# calamares-settings-titalcruise

Configuraciones personalizadas de *Calamares Installer* para *TitalcruiseOS*.

Este paquete ajusta el instalador del sistema para ofrecer una experiencia fluida, personalizada y con soporte completo para cifrado de disco completo (LUKS).

---

# Características

* Soporte completo para LUKS2: Instalación cifrada integrada con soporte para `cryptsetup` e `initramfs`.
* Secuencia de instalación optimizada: Configuración automática de usuarios, localización, particionado y gestor de arranque (GRUB).
* Integración con Refracta Snapshot: Detecta automáticamente las imágenes ISO vivas del sistema.
* Diseño e identidad visual de TitalcruiseOS: Integración con los temas y branding de la distribución.
